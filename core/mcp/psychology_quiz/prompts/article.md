# 心灵鸡汤文章成稿规则

宿主 Agent 收到用户提供的文章后，按以下规则产出配音正文。内容完整和观看体验优先，不限制成片时长。

## 压缩规则

1. 目标长度：正文去除空白后 1000 字左右（不少于 300，硬上限 1200）。
2. 原文不足 1000 字时直接使用原文，不做扩写、不加戏。
3. 原文的结构、段落顺序、黄金钩子（开头第一句）和关键金句必须逐字保留，禁止改写。
4. 只改细枝末节：删掉冗余例子、重复表达和过长铺垫，并顺滑衔接；不新增观点，不改变原意。
5. 正文中出现的任何品牌名、机构名一律替换为「财富研习岛」。
6. 每行不超过 20 个字符（TTS 与字幕的硬性要求）。
7. 语言保持朋友当面聊天的口吻。

## 片头场景

另写一句 `intro_scene` 片头写实图场景描述：人物身份 + 关键动作 + 环境细节，
要能概括文章最抓人的画面，供生成 16:9 写实片头图使用；禁止出现文字、标志和拼贴。

## 话题

`topic` 用一句话概括本文主题，作为 30 天话题去重依据；不得与最近主题同义重复。
