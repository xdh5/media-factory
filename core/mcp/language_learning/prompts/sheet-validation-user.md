检查这张去背景后的完整主题图。画布为 2 行×5 列，共 10 个主体，按上排从左到右、下排从左到右排序。

必须逐项检查：
1. 数量：是否正好 10 个彼此独立的主体
2. 完整性：每个主体是否完整、未被裁切、未与其他主体重叠或粘连
3. 文字：是否出现任何文字、字母、数字、单词、标题、标签、注释或标牌
4. 水印：是否出现水印、品牌标识或平台角标
5. 画风：是否统一为清晰扁平插画风格，无照片感、3D 渲染感或明显风格混杂
6. 背景残色：主体轮廓或透明区域附近是否残留非常严重的，影响观感的原纯色背景的彩边、描边、光晕、色块或毛边

只返回以下 JSON：

{
  "valid": true,
  "failure_kind": "",
  "issue": "",
  "subject_count": 10
}

只有发现问题时才判定失败。`failure_kind` 必须从以下取值中选择一个：
- `background_edge`：背景残色
- `text`：出现文字
- `watermark`：出现水印
- `style`：画风不合格
- `count`：主体数量不是 10 个
- `completeness`：主体不完整、重叠或粘连

`issue` 必须具体说明问题和大致位置，便于下一次重新生成修正。
