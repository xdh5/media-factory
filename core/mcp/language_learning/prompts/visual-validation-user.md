检查图片是否同时满足以下条件：

1. 画面中恰好有 10 个独立主体物体。
2. 上排恰好 5 个，下排恰好 5 个。
3. 不存在任何可见文字、字母、数字、单词、标题、标签、注释、标牌或水印。
4. 识别整张画布使用的统一纯色背景，用中文颜色名称返回。

阴影、把手、锅柄、孔洞、反光和物体内部结构都属于其主体，不得单独计数。

只返回以下 JSON，不要 Markdown 或解释：

{
  "object_count": 10,
  "top_count": 5,
  "bottom_count": 5,
  "has_text": false,
  "background_color": "亮紫色",
  "boxes": [
    [左, 上, 右, 下]
  ],
  "reason": "一句中文说明"
}

boxes 必须正好包含 10 个主体的边界框，按上排从左到右 5 个、再按下排从左到右 5 个排序。坐标使用 0 到 1000 的整数相对坐标，边界框要完整包含对应主体及其把手、阴影等附属结构，不要包含相邻主体。
