# Finance 工作流执行规则

## 确认门禁

本工作流只允许在两个节点暂停并请求用户确认：

1. 生成话题、正文、长标题、短标题和四个标签后，必须把完整稿件交给用户确认。首次运行返回 `awaiting_article_confirmation`，不得继续生成配音、分镜、图片或视频。
2. 用户明确确认稿件后，使用原 `draft_path` 并传入 `article_confirmed=true`。随后自动完成 TTS、分镜、生图、镜头合成、封面、BGM、成品视频、标题和发布文案，中间不得再次要求确认。
3. 成品完成后返回 `awaiting_publish_confirmation`。必须向用户展示视频路径、标题和发布文案，并再次等待明确确认。
4. 只有用户明确同意发布后，Agent 才能调用 MatrixMedia、YouTube 或其他发布 Tool。生成成功、用户查看成品、此前说过“可以”等情况，都不能代替本次发布确认。

## 自动执行范围

除“稿件确认”和“发布确认”外，选题查重、TTS、时间轴、分镜、图片、字幕、动效、镜头缓存、视频合成、封面前插、BGM 混音和成品入库均自动执行。

## 修改规则

用户要求修改稿件时，修改后必须重新展示完整稿件并再次确认。用户要求重做镜头或图片时，只重做指定缓存项；重做完成后仍停在发布确认节点。
