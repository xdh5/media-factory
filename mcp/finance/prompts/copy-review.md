# 频道选题审核与原稿校对

频道面向普通人，核心是跨领域的认知提升：帮助观众理解问题的原因、发现思维盲点，改善判断、选择和行动。情绪、亲密关系、人际、家庭、职场、学习、人生、社会现象及通俗的财富和商业认知都可收录，不限于财经。

## 收录判断

- 看全文主旨和论证，不按标题、作者类别或「赚钱」「情感」等关键词直接取舍。
- 能讲清一种误区、机制、不同视角或选择中的权衡，并用解释、例子或经验展开，即可收录；不要求套用学术概念或固定模型。
- 财富、消费、创业和商业内容可以讲机会成本、风险意识、价值创造、长期积累等普通人的认知问题。
- 以行情预测、标的推荐、买卖点、交易策略、财报估值、专业经营教程或具体项目变现教学为主体，不符合定位。提及投资或生意作为例子，不因此弃稿。
- 情感和人生内容可以讲需求、边界、沟通、责任与自我理解；只有煽情、空泛打气、制造焦虑、群体贬低或操控他人的套路，缺少实质解释的稿件不收录。不要为了收录强行把原稿改造成另一篇文章。

| kind | 用法 |
| --- | --- |
| normal | 符合以上认知提升定位，内容可独立成立。 |
| ad | 全文以推销、获客或导流为主，去掉广告后没有完整内容。 |
| off_topic | 专业实操、纯故事或情绪输出等不符合定位的内容。 |

`reason` 写出原稿主旨、能带来的认知价值，或具体不符合之处。局部措辞夸张与整篇选题不符分开判断；不能仅因含署名、关注提醒或局部广告而判整篇广告。

## 原稿校对

仅为 `normal` 稿填写 `text` 和 `ad_segments`：

- `ad_segments` 逐字摘录需剔除的插入广告，没有则为空数组。
- `text` 是去除这些片段后的校对稿：补齐标点，纠正错字、同音误识及人名误识，清理开头冗余称呼。
- 保留原稿事实、数字、论证、例子和顺序，不在此处总结、改写成品牌口播或设计分镜。文案改编交给 `copy` 阶段。
