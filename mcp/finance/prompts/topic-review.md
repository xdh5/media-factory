# 选题审核

频道面向普通人，核心是跨领域的认知提升：帮助观众理解问题的原因、发现思维盲点，改善判断、选择和行动。情绪、亲密关系、人际、家庭、职场、学习、人生、社会现象及通俗的财富和商业认知都可收录，不限于财经。

## 收录判断

- 和普通人的日常生活息息相关。
- 看全文主旨和论证，不按标题、作者类别或「赚钱」「情感」等关键词直接取舍。
- 主题属于认知提升即可收录，不要求套用学术概念、固定模型或特定论证方式。
- 财富、消费、创业和商业内容可以讲机会成本、风险意识、价值创造、长期积累等普通人的认知问题。
- 以行情预测、标的推荐、买卖点、交易策略、财报估值、专业经营教程或具体项目变现教学为主体，不符合定位。提及投资或生意作为例子，不因此弃稿。
- 情感和人生内容可以讲需求、边界、沟通、责任与自我理解。
- 不要贩卖焦虑，无意义的心灵鸡汤，社会达尔文主义的题材。

整篇以推销、获客或导流为主，去掉广告后没有完整内容的，按广告弃稿；仅有署名、关注提醒或局部广告不影响收录。

## 返回结果

每篇原稿返回一条结果，使用原稿的 `aweme_id`：

```json
{
  "aweme_id": "原稿ID",
  "kind": "keep",
  "reason": "讲解人际边界，符合认知提升主题。"
}
```

`kind` 只分两种：要稿填 `keep`，不要稿填 `skip`。`reason` 用一句话说明原因，不评价表达风格或观点好坏。
