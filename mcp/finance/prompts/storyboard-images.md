按本期分镜画面描述生成图片，逐镜参考提供的风格图。

- 保持参考图的二维动物漫画风格：清晰黑色轮廓、暖色灯光、干净色块与柔和明暗，场景细节完整，气质轻松幽默。
- 主人公必须是参考图中的拟人大鹅：白色羽毛、细长脖子、橙色长喙、大眼睛与略下垂的眼皮、头顶少量翘起的羽毛。每个有角色出场的分镜都以这只大鹅为主角，同一期外形和服装保持一致。
- 配角可以是其他拟人动物，保持同一画风，不使用人类角色。已有分镜中的人类主角替换为这只大鹅，保留原本的动作、场景和人物关系。
- 内容随各镜台词与画面描述变化，不固定复刻参考图的茶水间、圆桌或角色数量。
- 图片为 16:9，主体与场景清晰，预留下方字幕空间；不复制参考图中的文字、水印或标识。
- 只生成静态图片，workflow 为各镜随机添加轻微缩放或平移动效。
- 默认保存为 generated-images/shot-001.png 等逐镜路径；workflow 优先使用已有图片，没有图片的镜头仍搜索实拍视频。生图模式需先完成全部图片再继续。
- 宿主 Agent 使用可用生图工具，将参考图作为图像输入，逐镜保存到 image_requests 的 output_path。完成后调用 finance_continue_production(workflow_id)；若另存位置，按镜头顺序传 image_paths。

MCP 不调用生图模型，只提供参考图、分镜和输出位置，接收图片并执行合成。
