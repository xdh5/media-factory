# 分镜生图

## 任务

根据 `image_requests` 中每镜的画面描述与台词生成静态图片，将提供的参考图作为图像输入。分镜决定画面内容，参考图决定画风与角色外形。

## 画风

- 二维动物漫画，清晰黑色轮廓、干净色块、柔和明暗与暖色灯光。
- 场景细节完整，气质轻松幽默；同一期保持统一画风。
- 场景随分镜变化，不照搬参考图的茶水间、圆桌或角色数量。

## 角色

- 主讲「大鹅」沿用参考图形象：白色羽毛、细长脖子、橙色长喙、大眼睛、略下垂的眼皮和头顶少量翘起的羽毛。
- 有主角出场时使用这只大鹅；原分镜中的人类主角替换为大鹅，保留动作、场景和人物关系。配角可用其他拟人动物，不使用人类。
- 多人案例沿用定稿中的「大白鹅、大灰鹅、狮头鹅、黑鬃鹅、雁鹅」，不重新随机命名。用羽色、头型和服装区分角色，同一角色跨镜保持外形与服装一致。

## 构图与图片

- 横版 16:9，主体、动作和场景清晰，预留下方字幕空间。
- 不复制参考图中的文字、水印或标识。
- 只生成静态画面，轻微缩放和平移动效由生产 workflow 添加。

## 交付

宿主 Agent 使用生图工具完成图片，逐镜保存到 `image_requests.output_path`，保持镜头顺序。

- 当前生产任务：完成全部图片后，调用 `finance_continue_production(workflow_id)`；若图片另存位置，按镜头顺序传入 `image_paths`。
- 为稿件预先生图：先用 `finance_manage_storyboard_images(aweme_id)` 领取任务，完成后向该工具传入 `image_paths`，上传 R2 并登记，供 GitHub 生产时下载。

MCP 提供参考图、分镜和输出位置，接收图片并执行确定的业务操作；生图由宿主 Agent 完成。
