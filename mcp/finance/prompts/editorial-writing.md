# 大鹅原创口播撰稿

吸收参考材料的主题、观点和有用内容，重新组织论证与表达，写成大鹅自己的认知提升口播，不逐句换词。

## 篇幅与结构

全文1600～2000字，约六分钟，按这条脉络展开：

**黄金钩子 → 固定开场 → 具体生活场景 → 回应观众疑问 → 解释原因 → 两三个行动建议 → 回扣主题 → 固定结束语。**

- 开场：大家好，我是大鹅，我们今天来聊一聊〔本篇主题〕。
- 结束：我是大鹅，关注我，帮助大家在复杂世界里，掌握确定的逻辑。
- 各部分自然衔接，不念小标题，不强行凑段落。讲清一个核心问题，别靠重复和口号补字数。

## 写作要求

- 钩子直接说具体困境、反差或疑问，让人想听下去，正文要回应它。不要每篇套同一种问句。
- 场景有动作和细节，分析讲清原因与结果，建议说清怎么做。别堆苦难、恐吓、空泛鸡汤和无依据的权威结论。
- 口语自然，先把句子写通顺、标点补完整，再按句意断行。不出现“原稿”“参考稿”“原作者说”等幕后说明。
- 全文大鹅独白，主角始终是大鹅，其他角色任选其他动物并保持一致。对话转为叙述，真实人物与引文保留必要归属。
- 清掉其他账号的署名、连载指涉和互动导流，只保留规定的开场与结束语。
- 钩子和开场合放第一行，结束语单独放最后一行；每行对应一个镜头，最多60字，不拆词、不乱插标点。

## 好坏案例

以下只示范写法，不照搬例句。

| 环节 | 坏案例 | 好案例 |
| --- | --- | --- |
| 钩子 | 今天讲一个提升认知的终极秘诀。 | 为什么别人一句质疑，你就急着解释一大堆？ |
| 场景 | 成年人都很惨，谁也看不起你。 | 你说好只回一条消息，放下手机时，却发现半小时已经过去。 |
| 分析 | 所有拖延都是认知低。 | 手机伸手就能打开，书却还收在柜子里，两件事开始之前的阻力就不同。 |
| 建议 | 从今天起必须彻底自律。 | 今晚先把手机放远，把要读的书放在手边，看看是否更容易开始。 |
| 吸收观点 | 沿原文顺序逐句换同义词。 | 提取核心观点，重新选择切入场景、组织推理，再给出自己的解释与建议。 |
