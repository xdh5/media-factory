# 大鹅口播改写

根据校对后的原稿，改写成大鹅单人讲述的完整口播。保留论证、例子、信息量和顺序，不补造经历、数据、引文或理论依据，不把原作者的职业、粉丝量和收益写成大鹅亲历。

## 文章结构

1. 黄金钩子：根据全文核心观点重新创作，不照抄原稿开头，具体写法见下方。
2. 开场白：大家好，我是大鹅，我们今天来聊一聊〔本篇主题〕。
3. 正文：围绕原稿内容展开。
4. 结束语：我是大鹅，关注我，帮助大家在复杂世界里，掌握确定的逻辑。

黄金钩子与开场白放在第一行，结束语独立放在最后一行。正文按句意和口播停顿断行，每行最多 60 字。

## 黄金钩子

- 先读懂正文，再从具体困境、反直觉观点、行为后果或需要权衡的问题中选一个角度。开头就让观众知道和自己有什么关系、为什么值得听下去。
- 用口语写一句完整、简短的钩子，只抓一个矛盾或疑问。可以直接说观点，也可以问具体问题。
- 留下正文能回答的信息缺口，不把全部答案提前讲完，也不只说半句或堆抽象名词。开场白后立即承接钩子，不再重复铺垫。
- 钩子承诺必须由正文兑现；不虚构统计、研究、亲历、收益或效果，不靠恐吓、群体贬低、玄学和空洞的「惊天秘密」吸引人。
- 钩子与固定开场白合计不超过 60 字。创作时比较几个不同角度，只返回最合适的一版，不输出候选和分析。

以下是根据教学资料改编的认知类对照例句，不是实测爆款；学习写法，不照搬与本篇无关的内容。

| 写法 | 坏案例 | 好案例 | 区别 |
| --- | --- | --- | --- |
| 具体困境 | 今天聊聊沟通的重要性。 | 为什么一被质疑，你就急着证明自己？ | 从空泛议题落到熟悉的反应。 |
| 反直觉 | 人际交往有很多学问。 | 越想让所有人满意，为什么越容易委屈自己？ | 给出矛盾，让人想听原因。 |
| 行为与后果 | 你必须提升认知。 | 明明只想刷五分钟，怎么一抬头又过了一小时？ | 用具体场景代替说教。 |
| 选择与权衡 | 成年人要懂人情世故。 | 帮忙到什么程度，会开始消耗一段关系？ | 提出有边界、能展开的问题。 |
| 内容承诺 | 看完这个视频，你再也不会紧张。 | 开会时越想表现自然，为什么反而更紧张？ | 不保证结果，聚焦正文能解释的机制。 |
| 完整悬念 | 只有真正聪明的人才知道这个秘密。 | 一句「随便」，为什么会让关心你的人不想再问？ | 说清对象和冲突，不靠身份优越感吊胃口。 |

## 改写要求

- 清理重复、无意义口头填充、连载指涉，以及原有自我介绍、署名和关注、点赞、评论、导流等话术。
- 对白、多人对话和访谈问答改为独白，完整转述各方观点、反驳和理由，不写角色轮流发言；作为分析对象的原话、名言可以引用。
- 原作者、账号署名及宣传性品牌统一替换为「大鹅」，历史人物和真实观点出处保留姓名。
- 主讲与案例主角始终是「大鹅」，不再给主角另起名字。其他匿名或虚构人物由你按情境选择狐狸、兔子、熊等其他动物，同一角色全文保持一致，不使用其他鹅名；历史人物与真实观点出处保留原名。
