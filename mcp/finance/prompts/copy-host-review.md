审核每篇待审转写，完成校对和生产定稿后，用 `finance_finalize_collection(context_path, reviews)` 一次提交当前全部待审作品。

## 1. 判断是否收录

| kind | 判定标准 |
| --- | --- |
| normal | 主旨属于认知觉醒、个人成长、励志、心灵鸡汤、人生感悟、人际或情绪成长。财富和创业经历可以作为例证。 |
| ad | 整篇以推销或导流为主；普通署名、关注提醒按上下文判断，不直接视为广告。 |
| off_topic | 以投资、经商、行情操作、赚钱实操为主，或不属于上述收录范围。 |

每篇填写 `aweme_id`、`kind` 和 `reason`。`reason` 写明具体判断依据；弃稿的 `text` 留空，不填写定稿。

## 2. 校对合格稿

- 将插入广告的原文逐字填入 `ad_segments`，从正文中删除；没有则填空数组。
- 通读剩余内容，补标点，纠正错字、同音误识和人名误识，清理开头冗余称呼，结果填入 `text`。
- 保留事实、数字、论证、过渡、例子、对话轮次和原有顺序，不总结或删减正常内容。

## 3. 编写生产定稿和分镜

合格稿填写 `editorial`，字段如下。

### 正文与开头

- `article`：以校对稿为基础，清理转写重复、无意义口头填充和连载指涉；按完整句意和自然口播停顿断行，每行对应一个分镜，台词最多 60 字。长句在分句或短语边界拆开，保持人名、数字和固定词组完整。
- `replacements`：将原作者、账号署名及宣传性品牌统一替换为「财富研习岛」，逐项记录 `from`、`to`。历史人物、引文出处和对话角色保留原身份。
- `db_source_hook`：从 `text` 第一个字开始，连续逐字摘录有效开头。
- `source_hook`：对 `db_source_hook` 仅做上述品牌替换，放在 `article` 开头。

### 分镜

- `storyboard`：按 `article` 的非空行顺序，每行输出「画面描述|搜索关键词」，与台词逐行对应，不写台词 ID。
- 相邻且内容相关的台词可合并为正文一行，合并后最多 60 字；话题、主体或场景变化时拆开。
- 画面用中文说明主体、场景、动作和关键细节，选择素材网站常见的单一实拍场景，不写动效或跨场景剧情。
- 关键词提炼主体、动作或场景，使用 2～5 个英文单词，以空格分隔。描述和关键词不含竖线，不加表头或代码围栏。
- 分镜与正文一起定稿入库；生产 workflow 直接用关键词搜索，不再生成分镜。

### 标题与封面

| 字段 | 要求 |
| --- | --- |
| topic | 本篇核心主题。 |
| title | 12～26 字的完整标题。 |
| short_title | 6～16 字的短标题。 |
| hashtags | 从具体议题、场景和核心概念中选四个不同标签，不带井号。 |
| cover_lines | 封面文字，一至三行，拼接后等于 `title`。 |
| cover_highlights | 从 `title` 原文中选取需要强调的文字。 |

## 4. 提交

提交前通读定稿，检查软广告、品牌残留、相邻重复署名和品牌堆叠，将审核结论写入 `reason`。

调用 `finance_finalize_collection(context_path, reviews)`；若返回 `continuation`，查询其任务并继续审核下一批。
