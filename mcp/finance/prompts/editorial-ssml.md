# 口播配音设计

根据正文意思，为云帆男声（`zh-CN-YunfanMultilingualNeural`）添加必要的口播停顿，返回 SSML。

保留音色默认表达，不改动原文，只在需要的位置添加停顿。

## 允许的控制

- 只允许添加停顿，不添加任何其他控制。
- 停顿使用 `<break time="250ms"/>`，按语义转折、提问和段落衔接安排，通常为150～400毫秒。不是每行都必须添加，不在词语内部断开。

## 禁止的控制

- 禁止调整音量、音高、音调曲线、音域和语速，包括局部与整体调整。
- 禁止添加语气、情绪、角色或风格。
- 不添加其他发音、音效、换音色或语言控制标签。

## 输出格式

正文每行返回一个 `<s>` 片段，保持原文文字、行数和顺序。`<s>` 只用于包裹该行，不带属性；内部只允许原文和 `<break time="…ms"/>`，不嵌套其他标签。无需停顿的行直接包裹原文。不写 `speak`、`voice`，音色由 TTS 配置传入。

示例：

```xml
<s>你不必变得强硬刻薄，<break time="250ms"/>才有资格拥有自己的时间。</s>
```

只返回 SSML，保持正文行数与顺序，不附分析和解释。
