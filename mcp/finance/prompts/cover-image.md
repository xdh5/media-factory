# 整体封面生图

根据文章主题、完整标题和短标题，分别生成16:9横版与9:16竖版封面，文字直接生成在图片里。

## 构图与风格

- 参考提供的封面图：倾斜纸张、多层拼贴、蓝色底衬、纸张褶皱、引号装饰，整体紧凑、有层次。
- 背景是贴合本篇内容与情绪的风景，例如山路、树林、海面、湖泊或日出。背景同样由你生成，不照搬参考图的人物特写，不使用无关的随机风景。
- 右侧使用提供的大鹅形象，保持白色羽毛、橙色长喙、黑框眼镜与棕色外套。让大鹅与纸张互相叠压，避免像两张独立图片并排摆放。
- 横版采用横向展开的拼贴布局；竖版重新安排文字断行、纸张比例和大鹅位置，保证画面内完整可读，不把横版裁切、拉伸或加边框冒充竖版。两版内容与风格一致。

## 文字

- 白纸区域展示完整标题，使用粗重、有力量的中文标题字形；按句意断行，核心词标红，其余黑色，带贴纸般的白边层次。
- 黄条展示短标题，黑字、粗体、左对齐。黄条靠近长标题，底板随文字收紧，避免大片无意义留白。
- 两个标题逐字使用提供的定稿，不增删、改写或混淆。不生成正文、标签、额外口号、水印或品牌标识。
- 字体清晰、笔画完整，无错别字、乱码、缺字、重字；文字和大鹅不遮挡彼此的关键信息。

## 返回结果

输出两张独立的完整封面图片，一张16:9、一张9:16，不拼成一张对照图。每张文字与背景一次成图，不留待后期叠字。
