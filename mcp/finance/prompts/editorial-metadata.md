# 发布文案定稿

根据主题和完整口播生成一套发布文案，不改正文，不增加事实、效果或收益承诺。各字段围绕同一核心问题。

## 字段要求

| 字段 | 要求 |
| --- | --- |
| `title` | 12～26字，具体问题、场景或观点放前面；不照搬第一句，不用夸张口号、同义词堆叠或无关热点 |
| `short_title` | 6～16字，独立可懂，保留对象与矛盾；不机械截取长标题，不换主题 |
| `hashtags` | 四个不同的相关中文话题词，按相关性排序，不带井号、空格；不因业务名强加财经标签 |
| `cover_lines` | 完整标题按语义分成一至三行，拼接与 `title` 完全一致，不拆词、不让标点单独成行 |
| `cover_highlights` | 从标题中选已有的核心词，不整句强调 |
| `micro_summary` | 约150字独立摘要，概括问题、观点与做法，不含自我介绍、片尾和标签 |
| `youtube_short_selection` | 正文中最精彩的连续约500字，不改写、不拼接、不含固定片尾；精彩程度优先，不强求脱离上下文独立听懂 |
| `youtube_description` | 前两行说明本期问题和观看价值，自然包含核心关键词；随后介绍观点与启发，末尾自然邀请讨论或订阅。不堆关键词、不复制全文、不写章节或时间戳 |
| `youtube_hashtags` | 恰好10个互不重复、直接相关的专用标签，不带井号、空格，按相关性排序 |

切片使用正文非空行从1开始的 `start_line`、`end_line`。`title_lines` 将完整标题按语义拆成一至两行，拼接与 `title` 完全一致，保留原标题标点供校验；显示时的去标点、颜色由生产处理。

四个通用标签与10个 YouTube 专用标签分别保存。上传标题由发布流程组合完整标题和四个通用标签，10个专用标签用于描述末尾，不另创 Shorts 标题。

## 网络化表达与话题词

- 标题、文案和两套标签的网络表达由宿主大模型根据本篇主题、场景和情绪直接选择，不为选梗联网检索，不维护固定词表，不宣称实时热度。
- 标题、短标题、封面重点词、摘要和 YouTube 说明优先采用普通观众会说、会搜的网络词与生活表达，少用心理学、经济学等专业名词。先写清具体处境、情绪与冲突，再选择贴合内容的词，不把术语换成另一组抽象口号。
- 四个通用标签与10个 YouTube 标签均按此原则选词。优先选择与正文直接相关的网络话题、生活场景和情绪表达，每篇独立选词，不反复套用同一组标签；不要求每个标签都是热梗，也不为凑数量堆同义词或无关热点。
- 保留能让观众认出主题的核心词，例如“讨好型人格”“精致穷”“沉没成本”，搭配网络表达，不因减少专业名词而删掉有辨识度的主题词。
- 网络词按实际语义使用，不机械替换专业概念，不把网络说法包装成科学理论。不熟悉或含义不明的梗不用，不自行猜造。
- 标签必须能在正文中找到对应内容；标题中的网络词必须由正文兑现。适合自嘲的词不用于给观众贴负面身份标签。
- 本规则用于后续新稿及用户明确要求重做的稿件，已有定稿保持原样。

## 输出

只返回一个 JSON 对象，包含上表全部字段。`hashtags`、`cover_lines`、`cover_highlights`、`youtube_hashtags` 为字符串数组；`youtube_short_selection` 为包含 `start_line`、`end_line`、`title_lines` 的对象，其余为字符串。不附候选、分析或代码围栏。
