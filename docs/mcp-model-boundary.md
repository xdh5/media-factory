# MCP 模型边界

MCP 不依赖、不调用外部文本、视觉理解或生图模型。内容判断和生成由宿主 Agent 完成。

## 保留入口

`core.tools.qwen_text.generate_text` 仅供 MCP 外的 GitHub 财经 Runner 使用，生成分镜与成片定稿。
聊天 Agent 仍通过自己的模型配置执行任务。

## 图片流程

- 财经使用 `agent_reference` 准备参考图任务，宿主生图后通过 `finance_save_images` 保存，再调用 `finance_commit_existing_images` 校验与入库。
- 语言学习只接收宿主图片；生成失败交回宿主处理，不调用外部生图接口。
- 动漫取证返回图片地址与本地路径，由宿主识别。
