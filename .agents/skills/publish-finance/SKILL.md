# 发布财经成片

使用 `publishing` MCP，业务线、内容类型和默认账号组均为 `finance`。

## 默认参数

- 日期：按用户指定的计划日期找成片；缺失或有歧义时询问。用户指定标题时通过预览定位 `production_id`。
- 平台：默认账号组内全部启用平台；用户指定时只用指定范围。
- 时间：默认北京时间第一篇 14:00、第二篇 18:00。只有一篇排 18:00；当天 14:00 已过或只指定 18:00 时只排一篇，优先第二篇。明确指定其他时间只排一篇；明确要求现在就立即发布。默认时段均已过时，询问立即发布还是改约。
- 头条：滚动 7 天窗口的最远一天，第二篇 18:00 改为最晚可选小时，通常是 17:00。若确认为小时选项不可用且未提交，只调整该条，保持原日期。

## 执行

1. 调用 `publishing_list_account_groups`，再用 `publishing_start_account_check` 和 `publishing_poll_task` 检查实际授权。需要登录时展示平台和二维码或授权入口；页面、网络检测失败单独说明。全部通过前不恢复成片或上传；通过后提示 **全部账号已登录，开始发布**，自动继续。
2. 用 `publishing_preview` 核对产物、目标和重复记录；已发布或已预约的跳过。没有待发布成片就说明并结束。
3. 多日用 `publishing_start_batch`，每项传计划日期和 `content_kind="finance"`。单日诊断用 `publishing_start_publish`。默认时段由发布层计算，指定时刻使用带时区 ISO 8601。用户要求只做首日时，只启动首日。
4. 查询同一任务。批次每 3 分钟读取 `publishing_batch_status` 摘要，单日使用 `publishing_poll_task`。遇登录、验证码或平台限制立即提示；停滞先查最新状态或日志，提交结果不明先核对回执。最后按平台报告成功、预约、跳过和失败。
