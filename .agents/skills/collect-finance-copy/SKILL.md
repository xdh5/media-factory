# 收集财经文案

用户只需提供抖音分享链接或分享文字。分类固定为“财经”。用户要求保存即表示授权下载、转写并写入财经文案库，无需再次确认。

只通过 `finance` MCP 完成：

1. 调用 `finance_start_collect_copy`，原样传入 `share_text`，并固定传入 `collection_name="财经"`。
2. 使用返回的 `task_path` 调用 `finance_poll_task`，直到 `done=true`；不得为同一请求重复启动任务。
3. 成功后向用户展示转写文本、分类和入库结果。

禁止改用浏览器或临时脚本完成下载、转写或入库。MCP 未连接、进程退出或调用失败时，报告具体错误并停止。
