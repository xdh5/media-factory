# 生产语言学习预制图包

用户要求制作图包即表示授权生成词表、生图、验收并入库，无需再次确认，也不要询问计划发布日期。未指定主题时自主选择，按要求的数量完成。新增图包应避开已有图包主题、用户明确指出的已有主题及本批已选主题，忽略英文大小写；重复主题直接换新。`prepare_pack` 返回成功不代表主题未重复，不能将其作为主题查重结果。

只通过 `language_learning` MCP 完成。不占用成片话题，不创建成片 run。词表、定位和整图验收规则以 MCP 返回的 Prompt 为准。禁止绕过 MCP 执行业务流程或读写内部文件。

1. 先调用 `language_learning_get_topics` 查询数据库，选题时排除返回的 `pack_topics`。主题参数必须是一个不含空格的英文单词。调用 `language_learning_prepare_pack(topic)`，该工具会再次查询 D1 并拒绝已有图包主题；通过后才按返回的词表 Prompt 生成中英和韩英各 10 个词，再调用 `language_learning_validate_pack_words`。
2. 使用校验返回的唯一主体图 Prompt，生成一张包含十个主体的真实 Alpha 透明 PNG。不拆成十次生图，不用纯色背景代替透明。
3. 复用成片的定位与整图验收 Prompt：先 `language_learning_validate_pack_subject_sheet` 切图，再打开返回的实际切图验收图，调用 `language_learning_review_pack_subject_sheet`。
4. 切图不完整或带入相邻主体时先重新定位；图片内容不合格时才重新生图。彩色杂边可以接受，不得因此拒收或重新生成。
5. 验收通过后调用 `language_learning_commit_pack`，上传十张透明切图并入库；提交成功时十个单词同时写入现有查重词库，后续词包必须读取最新词库再选词，禁止一次准备多包后跳过重新查重直接入库。最近 100 天最多重复 5 个单词，超过 5 个必须重新选词。

GitHub 生产只领取已入库的图包，库里没有时不会临时生图。

参数格式、词表校验或主题不可用时，根据返回错误修正参数、重新选词或更换主题并继续，不得因单包失败中断整批。一次主题连续修正三次仍失败时换一个新主题。连接中断或服务错误可重试一次，仍失败时报告具体错误和已完成数量并停止。提交结果不明确时先核实是否已入库，禁止盲目重复提交。
