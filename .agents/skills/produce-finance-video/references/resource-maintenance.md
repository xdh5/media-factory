# 资源维护

## 预制片尾

资源位于 `workflows/finance/resources/`：`goose-outro-prepared.mp4`、`goose-outro-narration.wav`、`goose-outro-prepared.json`，随安装包和 GitHub 生产镜像分发。

日常生产不重复生成末句配音或字幕。正文追加预制原始音频和画面后统一混入 BGM。结束语、音色、语速或字幕样式变化时，同步重制三项资源。

重制片尾须沿用正文的 `_with_display_text` 字幕分页，每页单独计算底板宽度，左右各留24px；视频为1920×1080、30fps、1/15360时间基，避免拼接截短。核对实际成图和拼接后的片尾。

## 图片与缓存

工作流优先使用 `generated-images/shot-001.png` 等已有图片，实拍流程为缺图镜头搜索视频。图片从缓慢放大、缓慢缩小、从上向下、从下向上中选择运镜，相邻镜头不重复，结果随素材清单保存。合成器按指纹复用缓存；Shorts 按长片、切片范围和标题生成指纹，竖版布局只编码一次。

分镜图在北京时间过了计划日期，且全部目标已发布或到时预约后，由 Cloudflare 每小时清理；未预约或未到期保留。参考图、封面和成片不参与清理。
